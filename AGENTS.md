# Repository instructions

Keep each skill self-contained under `skills/<skill-name>/`, with a `SKILL.md` entrypoint and its required scripts, references, and assets.

Favor simple, maintainable changes. Open pull requests as non-drafts. Ask the user before pursuing a problem that has become too difficult.

GPT models must not choose visual design, including colors, layout, typography, spacing, imagery, or styling. Implement a user-specified design or approved reference; otherwise ask the user.
