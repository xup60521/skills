# T3 Code native work

Load only for T3 dispatch. The live host's orchestration instructions and actual tool schemas prevail. Ordinary work needs no T3 tools.

- Use the exposed native tool for a same-provider child with inherited settings that finishes this turn. Codex assignments use `fork_turns: "none"` with complete bounded context. Use `delegate_task` for another provider/model, explicit settings, background work or an isolated checkout. A subagent request never authorizes a top-level thread.
- Before the first delegate, read `orchestrator_capabilities` once per thread; refresh only after an error or owner-named provider change. Validate the enabled child-capable provider, exact model and model-local option IDs/values. Pass settings in `target.options`; inherit omitted settings. Never rename options, combine efforts across models or silently substitute an unavailable selection.
- Supply the complete frozen assignment, exact source, permitted paths, checks and limits. The child has no inherited conversation. Native/shared-checkout tools do not prove read-only access, credential isolation or OS containment. Apply ordinary worker rules and explicit owner choices.
- For isolation use the actual `isolation: "worktree"` control. Let the tool create and bind its checkout; never create a child's checkout in the shell or include checkout setup in its assignment. Shared-checkout writers require established authority and nonoverlapping ownership.
- Save actual task/thread handles, source/brief identity and provider/model/options in existing recovery records before dependent work. Reuse a supported request identity only to retry that same uncertain invocation, after inspecting its actual identity/effects. Pending, unknown and incomplete child results establish neither completion nor stop.
- Follow a running delegate's returned `next`. Do not poll through `task_status`, sleep, watchers, Monitor or ScheduleWakeup. Use the supplied completion notification. Cancel replaced or unneeded delegates with `task_cancel`, never an interrupt on a child-thread ID. Prove writers stopped before a replacement mutates.
- Each new review or re-check uses a new `delegate_task` containing the current brief, findings and objections, never `t3_thread_send`. Fix small findings directly. When the owner requests fewer/no delegates, cancel extras and start no replacements.
- V9 `3ways` retains its blind drafts and reciprocal debate. Keep immutable source, brief, target and handle identities at dispatch; reconcile resumed calls before new effects. The removed v8 execute/bind/complete helper API is not callable. Its idempotent recovery, exact controls and no-blind-replay guarantees are now host obligations.

Record actual result/stop controls and honest context/permission/family limits. Task completion never authorizes integration, publication or expanded scope.
